# Ep. 2: Give Mr. Done a Warehouse

**Dr. Sage and Mr. Done Adventures · AI for Business Leaders**

A one-minute explainer on how Claude Cowork keeps working across days: a project, project instructions, one local folder and plain `.md` notes.

▶️ [Watch](https://youtu.be/LSm6RFpHfeM) · 📖 [Article](https://www.caner.win/blog/dr-sage-and-mr-done-claude-cowork-project-folder) · 🌐 [www.caner.win](https://www.caner.win)

## The story → the real names

| In the story | In Cowork | What it does |
|---|---|---|
| Project office binder | Project | Keeps docs and context together across sessions |
| Site rules on the gate | Project instructions | Read at the start of every job |
| Work order | Your request | One task, with specs and a deadline |
| Fenced warehouse | Local folder | A folder on your computer; he works only there |

## Starter kit: copy this folder

```
WinterHouse/
├── Plan.md                     # what gets built, in what order
├── Budget.md                   # every cost against the limit
├── Shopping-list.md            # what to order and when
├── Logbook.md                  # what happened today, what's next
└── Project-instructions.md     # paste into your Cowork project instructions
```

1. Copy [`WinterHouse/`](WinterHouse/) to your computer and rename it for your own project.
2. In Claude Cowork, create a project and connect that folder.
3. Paste `Project-instructions.md` into the project instructions and edit it.
4. Give your order. Next session, ask: "Where are we?"
