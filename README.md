# Dr. Sage and Mr. Done Adventures

**AI for Business Leaders**

One-minute comic episodes that explain Claude in plain language, for non-technical business leaders.

🧠 **Dr. Sage** is Claude Chat: you think things through together.
🛠️ **Mr. Done** is Claude Cowork: you hand him the job and come back to finished work.

Each episode folder has the story, the real names, and a small starter kit you can copy.
